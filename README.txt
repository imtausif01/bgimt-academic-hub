BGIMT Academic Hub - Simple Public Website

WHAT IS INCLUDED
- One-page public website, no unnecessary multiple pages.
- Real BGIMT logo and campus image supplied by the user.
- BCA, BBA, B.Com, MCA, MBA sections.
- Official IKGPTU syllabus, notices, student portal and university links.
- BR Paper and PTU Study PYQ links.
- Course-wise YouTube channel links.
- ChatGPT and Google Gemini links.
- Google search button.
- Telegram contact/doubt section.
- Creator credit: Tausif Ahmad, BCA 2nd Year, Batch 2025-28.
- No PDF/resource files are stored by the website.

RUN IN CHROME
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the VS Code extension "Live Server" if needed.
4. Right-click index.html -> Open with Live Server.
5. Chrome will open the site.

IMPORTANT
The contact form is intentionally represented by a Telegram contact button because a pure static website cannot securely send form submissions to a private inbox without a backend/form service.

DEPLOYMENT
This is a static HTML/CSS/JS site and can later be deployed on GitHub Pages, Netlify or Vercel. No PHP/MySQL is required for this public version.

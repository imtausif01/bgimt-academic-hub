# 🎓 BGIMT Academic Hub

> A student-friendly academic resource website for BGIMT students.

**BGIMT Academic Hub** is a simple and user-friendly web project created to bring important academic resources for BGIMT students into one place. Instead of searching different websites and platforms separately, students can quickly access useful academic links, study resources, university information, and course-related content from a single website.

---

## 🌐 About the Project

The main purpose of BGIMT Academic Hub is to make academic resources easier to find and access for students.

The website provides organized sections for different courses and useful academic resources such as university links, syllabus information, notices, previous-year questions, study resources, and educational platforms.

This project was developed as a practical **Web Development project using HTML, CSS and JavaScript**.

---

## ✨ Features

* 🎓 Course-wise academic resources
* 📚 BCA, BBA, B.Com, MCA and MBA sections
* 📝 University syllabus and academic links
* 📢 Important notices and student resources
* 📖 Previous Year Question Paper resources
* ▶️ Course-wise YouTube learning resources
* 🤖 Quick access to ChatGPT and Google Gemini
* 🔍 Google Search integration
* 💬 Telegram-based contact/doubt section
* 📱 Responsive and mobile-friendly interface
* 🧭 Easy navigation between sections
* 🏫 BGIMT branding and campus visuals
* ⚡ Lightweight static website
* 🚀 Suitable for GitHub Pages deployment

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/imtausif01/bgimt-academic-hub.git
```

### 2. Open the project

Open the downloaded project folder in **VS Code**.

### 3. Run the website

You can either:

* Open `index.html` directly in your browser
* Or use the **Live Server** extension in VS Code

For Live Server:

```text
Right Click → index.html → Open with Live Server
```

The website will open in your browser.

## ⚠️ Important Note

The current version is a **static website** built with HTML, CSS and JavaScript.

It does not use PHP, MySQL or another backend/database system.

The contact/doubt functionality uses a Telegram contact option because a purely static website cannot securely process private form submissions without a backend or external form service.
